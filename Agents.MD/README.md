# Agents.MD Team Planning

Shared workspace for team planning artifacts across Overfished layers.

## Purpose

- Keep one source of truth for coordination across `frontend`, `api`, `ml`, `plugins`, and `databricks`.
- Track ownership, sprint goals, dependencies, and risks before implementation.
- Keep project-level planning separate from feature-level docs in each package.

## Suggested files

- `TEAM_WORKBOARD.md` for current sprint status and blockers.
- `OWNERSHIP.md` for role assignments and handoff rules.
- `DECISIONS.md` for short architecture decisions and rationale.

## Ground rules

- Keep entries short, dated, and actionable.
- Use links to code paths (for example: `api/src/overfished_api/ports/agent.py`).
- Prefer checklists with clear owners and due dates.
